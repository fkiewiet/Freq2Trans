# Data Versions: What Is Good, Old, Or Blocked

## Good Now

```text
/orcd/pool/006/fkiewiet/freq2transfer/datasets_N9600/up_N9600_seed42_repaired
```

Use for:

```text
field-loss warm-start training
capacity/depth experiments
CSL beta=0.3 FGMRES benchmarking
training-curve comparisons
```

Why good:

```text
Gate 0 audit passed.
No tiny/all-zero target fields in 16->32, 32->64, or 64->128.
```

Limitation:

```text
No source_im.npy.
Not sufficient for a thesis-grade exact complex residual loss.
```

## Old / Bad For New Claims

Old local/stuck/partially repaired datasets:

```text
experiments/claude/datasets/up_N9600_seed42_old_*
experiments/claude/datasets/up_N9600_seed42_stuck_*
any non-audited up_N9600_seed42 variant
```

Do not use for new claims. They are debugging history.

Old residual-weighted sweeps:

```text
phase1_residual_up_20260501
```

Treat as exploratory only. The residual term there is a proxy, not exact
`A_high u_pred - f`.

Green-trained operators:

```text
Green/raw-style baselines
```

Drop for 2D thesis direction. The 1D study already showed they are
operator/PML-incompatible and do not provide the solver behavior we want.

## New / Useful Pilot

Complex-source Green-style pilot:

```text
up_N1200_seed42_green_complex_source_v1
```

Use for:

```text
testing whether u_low + complex source improves warm-start prediction
testing source-conditioning architecture safely
```

Do not use for:

```text
claiming exact FD/PML residual loss
```

Reason:

```text
This pilot stores source_im.npy, but the solutions are still generated by the
same analytic Green-style pipeline unless explicitly changed.
```

## Future Gold Standard

FD/PML exact-source dataset:

```text
up_N1200_seed42_fdpml_complex_source_v1
```

Use for:

```text
exact residual loss: ||A_high u_pred - f|| / ||f||
```

Requirement:

```text
u_low and u_high must be generated by the same FD/PML operator family used in
the CSL/FGMRES benchmark, and the full complex source must be stored.
```

This is heavier and should be piloted small before attempting N9600.
