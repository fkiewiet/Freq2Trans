## Short project summary

I study a 1D Helmholtz problem with PML boundary treatment. The current method
uses a complex-shifted Laplacian (CSL) as a first-stage correction and trains a
learned map only for the remaining post-CSL defect.

For a vector `y` handed to the preconditioner, the learned preconditioner has
the form

```text
z0   = CSL_H^{-1} y
r2_H = y - A_H z0
c_H  ≈ A_H^{-1} r2_H
M^{-1} y = z0 + c_H
```

So the learned part is not replacing CSL. It only tries to correct the residual
that CSL fails to remove.

The correction target is scaled during training:

```text
target = c_H / (gamma * ||r2_H||)
```

At inference time the scaling is reversed, so the deployed preconditioner is
still `z0 + c_H`. This scaling was essential: without it, training appeared to
plateau at a useless loss; with it, the correction became learnable.

## Main empirical results so far

The strongest completed results are for right/Flexible GMRES, where the learned
post-CSL correction is applied at every preconditioner call. The experiments use
homogeneous 1D PML problems, `n=512`, `npml=112`, and beta `0.3` for the current
frequency ladder.

| High frequency `omega_H` | Low frequency `omega_L` | CSL-only baseline | Learned post-CSL result |
|---:|---:|---:|---:|
| `16` | `8` | about `8--9` iterations | plain G6 median `3` |
| `32` | `16` | median `10` | plain G6 / `pmlfeat` median `4` |
| `64` | `32` | median `13` | plain G6 / `pmlfeat` median `5` |

All ordinary right-FGMRES evaluations converged on all tested right-hand sides,
and final true residuals stayed below `1e-6`.

The main limitation is runtime: the current Python/PyTorch implementation is not
wall-clock faster than CSL-only, even though it reduces iteration counts. I am
treating this as a mathematical preconditioner result first, not yet an
optimized implementation result.

## Why the current question is subtle

The above success is in right/Flexible GMRES. I also computed a
left-preconditioned residual proxy along the same right-FGMRES trajectory, and
that proxy generally agreed with the true-residual iteration-count conclusion.

However, this is not the same as running an actual left-preconditioned Arnoldi
process. The advisor/Kees-style formulation applies

```text
w = M^{-1} A_H v_j
```

inside Arnoldi. For a nonlinear or input-dependent learned map, this changes the
distribution of vectors that the network sees. Right and left preconditioning
are not simply interchangeable here.

I tested the existing right-trained `pmlfeat` checkpoint inside this actual-left
Arnoldi action. It failed badly on a seed-2025 smoke test:

| Method inside actual-left check | Left residual result | True residual safety | Interpretation |
|---|---|---|---|
| CSL-only | left median about `9`, left convergence `50/50` | true residual was only marginal at the left stop | CSL left formulation behaves sensibly but is not perfect under true-residual safety. |
| right-trained `pmlfeat` | left median hit sentinel `1000`, only `3/50` left convergence | true residual around `1e-4` | Right-trained learned map is not stable as a drop-in left Arnoldi action. |

I do not interpret this as invalidating the right-FGMRES result. I interpret it
as evidence that the actual-left formulation needs a different training
distribution.

### 4. Strongest publishable direction

I see several possible directions, but I am not sure which is the most
publishable from a numerical mathematics perspective:

1. **Post-CSL learned defect correction as a robust right-FGMRES preconditioner.**  
   This is the strongest empirical result so far: clear iteration reductions
   across `omega_H=16,32,64`.

2. **Actual-left learned preconditioning.**  
   This would align better with a classical preconditioned Arnoldi story, but it
   may fail if the nonlinear map is unstable under the left action.

3. **Fixed/linear transfer operators after CSL.**  
   Instead of a nonlinear CNN preconditioner, learn or design linear
   `T_down/T_up` operators:

   ```text
   z0_H  = CSL_H^{-1} y
   r2_H  = y - A_H z0_H
   q_L   = T_down r2_H
   c_L   = A_L^{-1} q_L
   c_H   = T_up c_L
   M^{-1} y = z0_H + c_H
   ```

   This may be more compatible with standard GMRES theory.

4. **Frequency-transfer / multilevel interpretation.**  
   Treat frequency levels like a coarse-correction hierarchy: restrict the
   high-frequency post-CSL defect to a lower-frequency problem, solve/correct
   there, and lift the correction back.

My current instinct is:

- keep the right-FGMRES post-CSL correction as the solid empirical result;
- use the actual-left experiment as a formulation gate;
- if nonlinear actual-left fails, pivot toward fixed/linear transfer operators,
  because that may be a cleaner numerical-methods contribution.

I would like your view on whether that is the right prioritisation.
