### 1.2 Four key changes in `train_transfer.py` vs train4

**Change 1 — RMS normalisation**
Per-sample rms = √(mean(|u_low[interior]|²)) + 1e-8. Both u_low and u_high
are divided by the same rms, preserving the amplitude ratio the network must
learn. The zero predictor is analytically 100% and verified on data as a
normalisation sanity check.

**Change 2 — Imaginary channel in loss**
L = λ₁·MSE_re + λ₂·RelL2_re + λ₃·residual + λ_imag·RelL2_im.
Motivated by Exp 1A (2026-03-13): Im channel stuck at 53% with λ_imag=0.
L_imag is always logged regardless of λ_imag. Phase 1 searches over
λ_imag ∈ {0.0, 0.1, 0.3, 1.0}.

**Change 3 — Cosine annealing with warm restarts**
T_0=50, T_mult=2, η_min=1e-6. LR restarts at epochs 50, 150, 350, 750.

**Change 4 — Extended patience**
max_epochs=1000, patience=150. Early stopping spans two full restart cycles.

### 1.3 Dataset format: .npz → directory of .npy files

**Problem:** 5 arrays × 14400 × 512² × float32 ≈ 72 GB. Pre-allocating in RAM
crashes any machine.

**Solution:** `np.memmap` (disk-backed) during generation; `mmap_mode='r'` at
load time. The OS pages in only what each `__getitem__` call touches (~5 MB/sample).

**Format:**
```
datasets/up_N4800_seed42/
    u_low_re.npy   u_low_im.npy
    u_high_re.npy  u_high_im.npy
    source_re.npy  rms.npy  omega_low.npy
    metadata.json
```

## 2. Data generation

| Dataset | Server | Workers | Samples | Disk | Status |
|---------|--------|---------|---------|------|--------|
| `up_N4800_seed42` | wave5c | 30 | 14400 (3×4800) | ~75 GB | **COMPLETE** |
| `down_N4800_seed42` | wave5c | 30 | 14400 (3×4800) | ~75 GB | **COMPLETE** |

wave5f.mit.edu was not accessible (SSH key issue). Both directions generated
sequentially on wave5c. Total generation time: ~18h.

**Physics:** 2D free-space Green's function G(r) = (i/4)H₀⁽¹⁾(ωr), FFT
convolution with 2× zero-padding. 3–6 Gaussian sources per sample, amplitudes
∈ [1,2], phases ∈ [0, 2π]. No PML, no sparse solve — 100–1000× faster than FD.

**Nested seed design:** seed(pair=p, sample=s) = 42 + p·N_max + s. The first N
samples of any sub-dataset exactly match a standalone N-sample generation, so
the training script slices at load time — no re-generation needed.

## 4. Baselines (defined consistently across all scripts)

| Baseline | Definition | Expected value | Purpose |
|----------|-----------|----------------|---------|
| Zero predictor | Predict 0 everywhere | RelL2 = 100.00% always | Normalisation sanity check |
| u_low predictor | Use u_low as prediction of u_high | Varies by pair | Physics difficulty metric |
| Doubling test | ‖N(2u) − 2N(u)‖ / ‖2N(u)‖ | 30–50% (InstanceNorm) | Scale-equivariance diagnostic |

---

## 5. What to check when Phase 1 results arrive (~2 days)

1. **Zero baseline** = 100.00% ± <0.1% on every run — any deviation is a normalisation bug
2. **Best λ_imag** — pick the value minimising both RelL2_re and RelL2_im (prior: λ=0.3)
3. **Doubling test** — flag if <10% (suspiciously good) or >60% (severe scale nonlinearity)
4. **Val/train ratio** < 1.5 — check for overfitting at N=1200
